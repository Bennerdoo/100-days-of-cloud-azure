# 100 Days of Cloud Azure

This repository contains my learning notes and documentation for the "100 Days of Cloud Azure" journey.

## Overview

The goal of this project is to document hands-on Azure cloud learning experiences, one day at a time. Each topic is captured in a markdown note with step-by-step guidance, examples, and supporting screenshots or images.

## Repository Structure

- Day 1 - Create SSH Key Pair for Azure Virtual Machine.md — notes and solution steps for the first Azure task
- images/ — supporting images used in the notes

## What You Will Find

- Azure-related tasks and exercises
- Step-by-step solutions
- Markdown notes for easy reading and sharing

## How to Use

1. Open any of the markdown files in the repository.
2. Review the instructions and solution steps.
3. Use the images folder for visual references when needed.

## Notes

This project is primarily documentation-based and is intended for learning and reference purposes.
